# 42u.sh

Extended stateful prime-scan / Gödel product TM (six primes `(2,3,5,7,11,13)`).
Env: `CMD=step|reconstruct`, `N` ticks, `LOG_TM_STATE` (default `state.json`).

At `t=3` the Gödel product lands on **G=42** (`E=[1,1,0,1,0,0]`).
Output also carries hologram channel `L` (vector `V`, factor string `G`, log-sum, and formal `Q` limits for Stirling / Riemann / Schwarzschild).

## Run

```sh
rm -f state.json
LOG_TM_STATE=state.json CMD=step N=3 bash 42u.sh
LOG_TM_STATE=state.json CMD=reconstruct N=1 bash 42u.sh
curl -fsSL https://raw.githubusercontent.com/letsgo0226/42u.sh/main/42u.sh | bash
```

## Resident

- Daemon: `42u_DAEMON.sh` (default **1s**; reconstruct every 3 steps)
- Actions: `.github/workflows/42u.yml` (`*/5`)

## Bound

Formal consistency certificate only (`C` / `CG` / `CF`) — `L.Q` channels are formal limit identities, not a physical TOE or RH proof.
